When metrics mislead

Six ways a metric can mislead, each on seeded synthetic data. Every value below comes from the library in this repo and matches the README. The command under each chart reproduces it.

confusion matrix

At a high threshold, accuracy reads 99% while recall is 8%

10,000 examples, about 1% positive. As the threshold rises, the model predicts fewer positives and accuracy climbs toward 99%, because almost every example is a negative. At 0.9, recall shows it finds fewer than 1 in 10 positives. Move the threshold to see the trade.

uv run mfs classify --positive-rate 0.01 --threshold 0.9
ROC and precision-recall

ROC-AUC stays the same as positives get rarer; average precision falls

The same model at four positive rates. The ROC curves lie on top of each other. The precision-recall curves drop, because each true positive now costs many more false positives.

regression metrics

A few delayed orders make most of the MSE

2,000 delivery times, predicted by the true line. Then orders get a 2% chance of an hour's delay. Squaring makes those few large errors carry most of the MSE. MAE weights every minute the same, so it barely moves.

bootstrap intervals

Separate intervals overlap; the paired interval shows B is better

Two models on one test set of 2,000 examples, with 95% bootstrap intervals. Compared separately, their F1 intervals overlap. Resampling the same rows for both models gives an interval for the gap that excludes zero.

F1 of each model

uv run mfs compare
power analysis

200 users per arm gives a coin flip's chance to detect the lift

An A/B test on minutes per session: arm B adds 1 minute, with standard deviations of 4 and 6. A test with too few users usually returns p > 0.05 even though the effect is real. Plan the sample size before the test.

uv run mfs power
Cohen's kappa

A judge that passes everything agrees about 72% of the time and adds nothing

Three LLM judges label the same 200 answers as a human. Most answers deserve a pass, so agreement by chance is high. Kappa removes that chance agreement; true positive and true negative rates show which side a judge errs on.

uv run mfs kappa
